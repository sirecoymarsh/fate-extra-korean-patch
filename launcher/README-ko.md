# Fate/EXTRA 한국어 패치 런처 1.5.0

본편 설치 방식에 **외부 데이터 로딩 · ISO 생성 안 함**을 추가했습니다. 기존 ISO 파일 생성 방식도 계속 사용할 수 있습니다.

## 사용 방법

1. ZIP 전체를 풀고 `FateExtraLauncher.exe`를 실행합니다. 기존 런처를 업데이트할 때는 런처와 게임을 종료하고, 기존 폴더에 새 EXE와 tools를 덮어씁니다. launcher-settings.json과 Data는 보존합니다.
2. 일본판 원본 ISO를 지정하고 본편 한국어 패치를 선택합니다.
3. 설치 방식에서 `외부 데이터 로딩 · ISO 생성 안 함`을 선택한 뒤 설치합니다.
4. PPSSPP와 메모리스틱 경로를 지정하고 런처의 게임 실행 버튼을 누릅니다.

외부 방식에서는 실행할 때도 원본 ISO가 필요합니다. 삭제하거나 이동했다면 원본 경로를 다시 지정하세요. 설치 방식 선택만 바꾸면 기존 설치를 계속 실행하며, 본편 설치를 실행해야 방식이 전환됩니다. 이전 방식의 설치 파일은 자동 삭제하지 않습니다.

게임 실행 중에는 작은 보조 프로세스가 필요한 데이터를 공급합니다. 런처 창은 닫아도 되며 게임을 종료하면 보조 프로세스도 종료됩니다. 외부 데이터의 patch.bin을 PPSSPP에서 직접 열지 말고 런처를 통해 실행하세요.

HD 팩·선택 UI·치트·클리어 세이브는 기존 선택 설치 기능을 사용합니다. 본편 외부 로딩에 인터넷 연결은 필요하지 않으며, 배포 자료 다운로드와 업데이트 확인에만 인터넷을 사용합니다. 실행 준비 중 취소하면 게임을 시작하지 않습니다.

v8h 기준 외부 변경 데이터는 약 1.09 GiB이며, 다운로드 캐시는 별도로 남습니다. 완성 ISO 약 1.84 GiB는 생성하지 않습니다. 원본은 읽기 전용으로 참조하고 실행 직전에 원본·데이터·조합 결과를 검사하므로 시작까지 잠시 걸릴 수 있습니다.

## 확인한 범위

- 실제 v8h 패치로 외부 설치, 새 ISO 파일 미생성, 원본 해시 보존
- 조합한 전체 이미지가 기존 v8h ISO SHA-256과 일치
- 구간 경계·임의 위치·잘못된 색인·HTTP 읽기 등 967개 검사
- 기존 런처 회귀 26개, 실행 기본 설정 27개, 설치 방식 UI·실행 상태 12개 검사
- 기존 ISO 생성 방식으로 실제 v8h 설치·결과 해시 확인
- Windows PPSSPP 1.20.4에서 새 부팅, 타이틀의 일반 세이브 로드, 한글 대사, 아레나 진입·이동, 네이티브 스크립트 일치, 보조 프로세스 종료 확인

본편 전체 루트와 모든 전투를 다시 플레이한 검증은 아닙니다. 외부 방식의 HD·선택 UI 조합은 전체 바이트 동일성과 기존 설치 경로 보존에 근거하며 이번 런타임 검사는 기본 텍스처로 수행했습니다. PSP 실기용 외부 로더는 포함하지 않습니다. 예전 상태 저장 대신 타이틀에서 일반 세이브를 불러와 시작하세요.

이 런처는 기존 배포 패키지를 그대로 사용할 수 있습니다. 내려받는 본편 버전은 배포 서버의 버전을 따릅니다. 본편 v8h / HD v54 / UI v4가 공개되었습니다. 새 버전을 확인하고 본편 설치 / 업데이트를 실행하면 적용됩니다.
