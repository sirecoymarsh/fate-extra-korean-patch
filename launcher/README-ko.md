# Fate/EXTRA 한국어 패치 런처1.4.1

PSP 일본판 Fate/EXTRA(NPJH50247)용 비공식 한국어 패치입니다.

**[최신 배포와 다운로드](https://github.com/sirecoymarsh/fate-extra-korean-patch/releases/tag/v8f-hd-v52-ui-v2)** — 본편 v8f · HD v52 · 선택 UI v2 · 런처1.4.1

## 설치

런처1.4.1 ZIP을 새 폴더에 풀고 실행합니다. 보유한 일본판 원본 ISO를 지정하고 설치할 항목을 선택한 뒤 **설치 / 업데이트**를 누르세요. HD/UI/치트/클리어 세이브는 PPSSPP 메모리스틱 폴더가 필요합니다.

| 선택 | 화면 |
| --- | --- |
| 본편 | 한국어 대사·설명 + 원래 영문 UI |
| 본편 + HD | 고화질 그림·글꼴 + 원래 영문 UI |
| 본편 + HD + UI 한국어화 | 고화질 + 한국어 UI·아이콘·전투 메시지 |

시작할 때 최신 배포를 확인하며 다운로드·적용은 버튼을 눌러야 진행됩니다. 런처 실행 파일 자체는 자동 교체하지 않습니다. 이미 적용한 UI 한국어화는 HD 업데이트 시 유지되며, 원래 UI로 돌아가려면 **UI 한국어화 해제**를 사용합니다.

## 이번 배포

- 본편 v8f: 기존 v8e에서 매트릭스 압축 자료 11곳의 로딩 오류를 수정했습니다. 대사·글꼴·UI 배치는 v8e를 유지합니다.
- HD v52: 승인한 v41~v52 그림 2,867장과 연결 정보 5,806개를 누적했습니다. 캐릭터, 매트릭스, 배경·소품, 문셀·최종전 돌기둥, 세이비어 눈동자, 디지털 숫자를 포함합니다.
- UI v2: 별도 선택 UI 한국어화와 원래 UI 복원 자료입니다.
- 런처1.4.1: 매트릭스 상세 화면의 감속·오디오 깨짐과 관련된 느린 인터프리터 설정을 JIT로 교정합니다. 기존 JIT/JIT-IR 선택을 유지합니다.

**실험 v51a의 추가 본편 글꼴·문구·UI 위치 변경은 포함하지 않습니다.** 전체 최신 실험 ISO를 그대로 배포한 버전은 아닙니다.

## PPSSPP 설정과 저장

HD/UI 설치 시 Fate/EXTRA 전용 설정에 렌더링 8배, MSAA 4배, 수직동기화·텍스처 교체 켜기를 적용합니다. 기존 JIT 설정과 전역 설정은 보존합니다. MSAA 지원과 성능은 백엔드·기기에 따릅니다. 설치·업데이트 전에는 PPSSPP를 종료하세요.

치트는 선택 설치입니다. PPSSPP의 치트 사용 기능만 켜며 개별 코드 19개는 모두 꺼져 있습니다. 클리어 세이브도 선택 설치이고 선택하지 않은 저장 데이터는 변경하지 않습니다. 동봉 클리어 세이브는 캐스터 Lv.52 / 37시간51분이며 치트 사용 이력이 있을 수 있습니다. 기존 같은 슬롯은 보관하세요.

새 ISO를 시작한 뒤 게임 타이틀에서 일반 저장을 불러오세요. 이전 PPSSPP 상태 저장에는 옛 실행 코드가 들어 있습니다.

기존 프로필은 새 런처에서 첫 게임 실행 시 CPU 설정만 한 번 교정하며 사용자가 조절한 해상도·음량·반향·치트 선택은 유지합니다.

## 경로 자동 탐색

- 자동 탐색과 **경로 자동 찾기**, **폴더 안에서 찾기…**는 선택한 설치 항목에만 적용됩니다. 본편만 선택하면 Windows의 PPSSPP 실행 기록이나 메모리스틱을 확인하지 않습니다. 치트·세이브만 선택하면 ISO는 찾지 않습니다.
- 런처 주변, 다운로드·바탕 화면, 드라이브의 `DOWN`, `Downloads`, `Games`, `Emulators`, `PSP`, `PPSSPP`, `ROMs` 폴더 및 일반 PPSSPP 설치 위치를 확인합니다.
- 현재 Windows 사용자에게 남아 있는 PPSSPP 실행 경로 기록을 먼저 확인합니다. 기록의 경로가 실제 PPSSPP 실행 파일과 `assets` 폴더로 이어지는지 검사하므로, 런처와 다른 드라이브에 설치되어 있어도 찾을 수 있습니다. 이 기록은 읽기만 하며 외부로 전송하지 않습니다.
- PPSSPP가 실행 중이면 해당 프로그램 위치도 확인합니다. 기존 PPSSPP의 최근 게임 기록에서 원본 ISO 후보와 같은 폴더를 찾습니다.
- ISO는 파일 크기와 내부 게임 정보(NPJH50247 / 1.01)를 확인합니다. 이름이 바뀐 원본도 탐지합니다. 전체 파일 검증은 실제 설치할 때 합니다.
- PPSSPP의 `installed.txt` 설정과 포터블 `memstick`을 확인합니다. 실행 파일과 떨어져 있는 메모리스틱도 `PSP/SYSTEM/ppsspp.ini`를 기준으로 찾습니다. 후보 프로그램은 탐색 중 실행하지 않습니다.
- 일반 위치에서 PPSSPP나 메모리스틱을 찾지 못하면 로컬 드라이브의 하위 폴더까지 추가로 탐색합니다. 1.1.0에서 놓치던 깊은 사용자 지정 설치 폴더도 탐색 대상입니다. 이 추가 탐색에서는 ISO 전체를 검색하지 않습니다.
- 찾은 후보는 원본 ISO·PPSSPP·메모리스틱 입력 칸의 **▼**에 표시됩니다. 여러 후보 중 PPSSPP를 선택하면 그 프로그램의 메모리스틱을 연결합니다. 같은 설치 폴더에 32비트와 64비트 실행 파일이 함께 있으면 목록에는 64비트만 표시합니다.
- 이미 지정한 경로와 직접 선택한 메모리스틱은 보존합니다. 설치 후에는 설치 경로가 고정되므로 PPSSPP를 바꾸어도 메모리스틱을 자동 변경하지 않습니다. 여러 후보는 임의로 선택하지 않으며, **경로 자동 찾기** 또는 입력 칸의 **▼**에서 고를 수 있습니다.
- 일반 위치 탐색은 최대 15초/2,500개 폴더, 추가 드라이브 탐색은 최대 45초/50,000개 폴더·32단계, 선택한 폴더 탐색은 최대 45초/20,000개 폴더·16단계입니다. 네트워크 경로, 연결된 폴더, 텍스처·세이브 등 대용량 데이터 폴더는 건너뜁니다. 한도 때문에 찾지 못한 경로는 **폴더 안에서 찾기…**로 상위 폴더를 좁히거나 `찾기…`로 직접 지정하세요.

## “Windows의 PC 보호 / 알 수 없는 게시자”

이 배포본은 **Authenticode 서명이 없는 프로그램**입니다. SmartScreen의 게시자·파일 평판이 없어서 경고가 표시될 수 있습니다. 파일 속성의 제작자 이름이나 다운로드 검증 정보는 신뢰된 디지털 서명을 대신하지 않습니다.

신뢰되는 코드 서명에는 발급자의 신원 검증과 인증서 또는 서명 서비스가 필요합니다. 새 프로그램은 정식 서명을 해도 평판이 쌓일 때까지 경고가 남을 수 있습니다. 자체 서명 인증서를 넣는 것으로 해결되지 않으며, 이 런처는 Windows 보안 설정이나 인증서 신뢰 저장소를 변경하지 않습니다.

직접 선택한 공식 GitHub 배포 파일인지 먼저 확인하세요. 출처를 확인하고 실행을 결정한 경우에만 경고창의 `추가 정보 → 실행`을 선택할 수 있습니다. 보안 정책에 따라 이 버튼이 없을 수도 있습니다.

Microsoft 공식 안내: https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation

## 업데이트와 실행

- 시작 시 버전만 확인합니다. 사용자 버튼 클릭 없이 설치하거나 세이브를 덮어쓰지 않습니다.
- 본편 설치 후 **게임 실행**을 눌렀을 때 PPSSPP·메모리스틱이 없다면 그때 실행용 경로를 선택합니다. 본편 패치 생성과는 별도이며, 게임 실행 전에는 PPSSPP가 없어도 됩니다.
- 본편 업데이트에도 원본 ISO가 필요합니다. 기존 패치 ISO에 다시 패치를 겹쳐 적용하지 않습니다.
- 다운로드를 취소하거나 연결이 끊기면 다음 시도에 이어받습니다. 받은 파일과 결과 ISO는 런처가 내부에서 확인합니다.
- PPSSPP를 종료한 뒤 업데이트하세요. 실행 중이면 설치를 중단합니다.
- 기존 HD가 새 본편과 맞는지 확인되지 않으면 HD도 함께 선택해야 합니다. 기본판만 쓰려면 HD가 없는 별도 메모리스틱으로 처음 설정하세요.
- 설치 이후 본편/메모리스틱 경로는 고정됩니다. 다른 설치를 만들려면 런처를 별도 폴더에 풀어 시작하세요.
- 런처는 사용자가 지정한 PPSSPP와 assets를 본편 폴더의 `emulator`에 복사하여 선택한 메모리스틱으로 실행합니다. 기존 PPSSPP 설치 설정은 고치지 않습니다.
- 본편·HD·선택 UI의 설치 버전, 경로와 선택 상태는 런처 옆 `launcher-settings.json`에 저장됩니다.
- 런처 자체의 새 버전이 필요한 경우 배포 페이지에서 새 런처 ZIP을 받아 기존 런처 폴더에 풀어 주세요. 실행 파일 자체를 자동 교체하지는 않습니다.

## 백업과 복원

기존 설치 항목을 교체할 때 같은 위치에 `.fate-backup-날짜-식별자`를 붙여 백업합니다. 다른 저장 슬롯은 건드리지 않습니다. 클리어 세이브를 선택하면 DATA80 슬롯을 교체하므로 자동 백업을 보관하세요. 동봉 세이브는 치트를 사용한 플레이에서 만들어졌을 수 있습니다.

설치 실패 시 이전 파일로 복원합니다. 설치 도중 강제 종료되면 다음 확인·설치·게임 실행 전에 미완료 작업을 복구합니다. 복구 오류가 나면 파일을 임의로 지우지 말고 로그와 `install-journal.json`을 보관하세요.

수동 복원은 PPSSPP와 런처를 종료한 다음, 교체된 해당 파일/폴더를 다른 이름으로 옮기고 백업 이름에서 `.fate-backup-…` 부분을 제거합니다. HD와 PPSSPP 설정을 함께 백업했으면 둘 다 복원하세요. 구버전 ISO는 본편 폴더의 `games`에 남습니다.

PSP용 CWCheat 코드는 치트 선택 설치 후 `Data/Extras/버전/Cheats/PSP`에서 수동으로 가져갈 수 있습니다. 런처가 PSP 기기에 자동 설치하지는 않습니다.

## 확인 범위

지원 원본은 일본판 `NPJH50247`, DISC_VERSION 1.01, 1,280,933,888 bytes입니다. 원본 ISO와 PPSSPP는 배포하지 않습니다. 실행 확인은 PPSSPP 1.20.4 기준이며, **PSP 실기 호환은 미검증**입니다. PSP 실기에서 PPSSPP용 HD 팩을 사용할 수 없습니다.

새 빌드는 게임 내 일반 저장 불러오기로 시작하세요. 이전 빌드의 PPSSPP 상태 저장에는 옛 실행 코드가 포함될 수 있습니다.
