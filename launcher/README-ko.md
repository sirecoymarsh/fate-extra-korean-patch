# Fate/EXTRA 한국어 패치 런처 1.6.0

한 번 켜면 필요한 경로를 스스로 찾고, 고를 것은 「전체 설치 / 본편만」 하나, 누를 것은 「설치」 하나입니다. 이후에는 새 배포가 있을 때 「업데이트」 한 번이면 됩니다.

## 처음 한 번

1. ZIP을 아무 폴더에나 풀고 `FateExtraLauncher.exe`를 실행합니다.
2. **"Windows의 PC 보호" 창이 뜨면 「추가 정보」 → 「실행」**을 누릅니다. 이 런처는 유료 서명이 없어 처음 한 번 이 경고가 나옵니다. 아예 안 보려면 ZIP을 풀기 전에 ZIP 파일 → 속성 → 아래쪽 「차단 해제」를 체크하고 풀면 됩니다. 파일이 바뀌지 않았는지는 배포 페이지의 `SHA256SUMS.txt`로 확인할 수 있습니다.
3. 런처가 일본판 원본 ISO·PPSSPP·메모리스틱을 찾아 칸을 채웁니다. 못 찾은 칸만 「찾기…」로 지정하세요.
4. 「전체 설치」가 골라져 있습니다. 「설치」를 누르면 다운로드부터 설치까지 진행합니다.
5. 끝나면 「게임 실행」을 누르고, 타이틀 화면에서 「로드」로 일반 세이브를 불러옵니다.

전체 설치는 본편 + HD 고화질 + 한국어 UI로 약 2.4GB를 받습니다. PPSSPP 없이 ISO만 만들려면 「본편만」을 고르세요.

## 그다음부터

- 켤 때마다 최신 배포를 확인합니다. 새 버전이 있으면 큰 버튼이 「업데이트」로 바뀌고, 한 번 누르면 됩니다. 기존 파일은 옆에 백업됩니다.
- 경로와 선택은 기억합니다. 다시 묻지 않습니다.
- 런처 자체를 새로 받은 경우에는 기존 폴더에 EXE와 tools만 덮어쓰세요. `launcher-settings.json`과 `Data`는 그대로 둡니다.

## 고급

「고급 ▾」를 열면 항목별 선택(본편·HD·한국어 UI·치트·클리어 세이브), 본편 설치 방식, 설치 폴더, 경로 다시 찾기, PPSSPP 기본 설정 적용, 한국어 UI 해제, 진행 기록이 있습니다.

- **본편 설치 방식**은 「한국어 ISO 파일 만들기」가 기본입니다. 「외부 데이터 로딩」은 ISO 파일을 만들지 않는 대신 실행할 때마다 원본 ISO가 필요하고, 런처의 「게임 실행」으로만 시작할 수 있으며, 첫 실행 준비에 디스크 속도에 따라 몇 분이 걸릴 수 있습니다. 방식을 바꾼 뒤에는 「설치」를 다시 눌러야 적용됩니다.
- 치트는 설치해도 전부 꺼져 있습니다. PPSSPP의 치트 목록에서 필요한 것만 켜세요.
- 만들어진 한국어 ISO는 설치 폴더의 `Data\games` 안에 있습니다. PPSSPP에서 직접 열어도 됩니다.

## 문제가 생기면

설치 폴더의 `Data\launcher.log`에 진행 기록이 남습니다. 문의할 때 이 파일과 화면의 안내 문구를 함께 알려 주세요.

- 여유 공간: 설치 폴더 드라이브에 전체 설치 기준 약 7GB, 본편만이면 약 5GB가 잠시 필요합니다.
- 메모리스틱 칸에는 `PSP` 폴더를 품은 폴더를 지정합니다. `PSP` 폴더 자체를 고르면 런처가 알아서 위 폴더로 바꿉니다.
- OneDrive 같은 동기화 폴더 안의 경로는 거부합니다. 동기화 밖으로 옮겨 주세요.

## 그림

런처 머리의 키 비주얼과 로고는 여러분이 지정한 원본 ISO 안의 게임 자체 그림(`PSP_GAME/PIC1.PNG`, `ICON0.PNG`)을 실행 때 읽어 보여 주는 것입니다. 런처 ZIP에는 게임 그림이 들어 있지 않습니다.

## 이 런처가 하는 것과 하지 않는 것

- 받은 모든 파일과 원본 ISO, 만든 결과물은 크기와 SHA-256을 통과해야만 씁니다. 원본 ISO와 여러분의 PPSSPP 설치본은 바꾸지 않습니다.
- 인터넷에서 받은 것을 실행하지 않습니다. 압축 해제와 패치 적용 도구는 런처에 동봉돼 있고 해시로 대조합니다.
- 게임 ISO와 에뮬레이터는 제공하지 않습니다. 지원 원본은 일본판 NPJH50247 / 1,280,933,888바이트입니다. PSP 실기는 미검증입니다.
