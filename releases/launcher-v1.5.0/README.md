## 런처 1.5.0 — 새 ISO 없이 외부 데이터로 실행

설치 방식에 **외부 데이터 로딩 · ISO 생성 안 함**을 추가했습니다. 기존 **ISO 파일 생성** 방식도 사용할 수 있습니다.

1. 아래 `Fate-Extra-Korean-Launcher-v1.5.0.zip` 전체를 압축 해제합니다.
2. 일본판 원본 ISO를 선택하고 본편 설치 방식과 필요한 HD/UI 항목을 선택합니다.
3. 설치가 끝나면 런처의 게임 실행 버튼으로 시작합니다.

기존 런처를 업데이트할 때는 런처와 게임을 종료하고 새 EXE와 tools를 덮어씁니다. 기존 `launcher-settings.json`과 `Data`는 보존하세요. 방식 선택만 바꾸면 기존 설치가 전환되지는 않습니다.

외부 방식은 실행할 때도 원본 ISO가 필요합니다. 게임 중 런처 창은 닫아도 되며, 게임 종료 시 보조 프로세스도 종료됩니다. 게임 데이터는 이 컴퓨터 안에서 공급하며 플레이에 인터넷 연결은 필요하지 않습니다.

**이번 릴리즈는 런처만 업데이트합니다. 현재 공개 본편은 v8g / HD v53 / UI v3입니다.** [본편·HD·선택 UI 배포 페이지](https://github.com/sirecoymarsh/fate-extra-korean-patch/releases/tag/v8g-hd-v53-ui-v3)에서 기존 수동 설치 파일도 받을 수 있습니다. v8h 본편은 이 릴리즈에 포함되지 않습니다.

검증: 현재 공개 v8g를 빈 캐시에서 실제 다운로드해 외부 설치했고 전체 조합 SHA-256 일치와 ISO 미생성을 확인했습니다. 별도 v8h 기준 967개 데이터/전송 검사, 기존 설치 26개·실행 설정 27개·UI/상태 12개 검사를 통과했습니다. PPSSPP 1.20.4에서 새 부팅·일반 세이브 로드·한글 표시·아레나 진입/이동·정상 종료도 확인했습니다. 최종 변경은 실행 상태 표시이며 관련 검사를 다시 통과했습니다.

본편 모든 루트·전투 또는 외부 방식의 모든 HD/UI 조합을 재검증한 것은 아닙니다. PSP 실기용 외부 로더, 게임 ISO, 에뮬레이터는 포함하지 않습니다. 지원 원본은 일본판 NPJH50247 / 1,280,933,888바이트입니다.
