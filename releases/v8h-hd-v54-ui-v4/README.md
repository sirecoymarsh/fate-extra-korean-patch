아처·세이버의 캐릭터 연출 명령 손상을 복구한 **본편 v8h**를 공개합니다. 기존 v8g 사용자는 업데이트한 뒤 타이틀의 일반 세이브로 이어 하세요.

- 문자열 재배치 과정에서 주소로 잘못 바뀐 **아처 2곳·세이버 13곳**의 연출 명령을 원본으로 복원했습니다. 지정된 15개 명령의 30바이트가 변경되었습니다.
- 기존 v8g의 번역·글꼴·이름 표시·매트릭스 수정은 유지됩니다.
- **HD v54·선택 UI v4**는 v8h에 맞춘 호환성 패키지입니다. 그림과 매핑은 HD v53·UI v3과 같습니다.
- **런처 1.5.0**을 포함합니다. 기존 ISO 생성 방식과 **외부 데이터 로딩 · ISO 생성 안 함**을 선택할 수 있습니다.

### 설치

1. PPSSPP를 종료하고 아래 런처 1.5.0 ZIP을 압축 해제합니다. 기존 런처를 교체할 때는 `launcher-settings.json`과 `Data`를 보존하세요.
2. 보유한 일본판 원본 ISO를 지정하고 본편·HD·UI 등 원하는 항목을 선택해 **설치 / 업데이트**를 누릅니다. 이미 1.5.0을 사용 중이면 새 버전 확인 후 업데이트하면 됩니다.
3. 외부 데이터 방식은 실행할 때도 원본 ISO를 보관해야 하며 런처의 게임 실행 버튼을 사용합니다. 방식 선택만 바꾸면 기존 설치는 전환되지 않으므로 본편 설치를 실행하세요.
4. 새로 부팅한 게임 타이틀에서 **로드**로 일반 세이브를 불러옵니다. 이전 PPSSPP 상태 저장에는 수정 전 실행 코드가 남아 있을 수 있습니다.

수동 본편 설치는 Base ZIP의 `Apply-Patch.cmd`를 실행해 일본판 원본 ISO를 선택합니다. HD 분할 압축은 `.z01`과 `.zip`을 같은 폴더에 두고 ZIP에서 풉니다. 자세한 수동 설치는 `INSTALL-ko.txt`를 참고하세요.

### 확인 범위

원본 ISO에서의 재생성, 지정한 30바이트 외 변화 없음, 캐릭터 명령 영역·포함 경로 검사, 실제 패키지 적용 결과 해시를 확인했습니다. 본편+HD+선택 UI 설치와 UI 적용/해제, PNG 26,712장의 해시도 확인했습니다. 런처 1.5.0의 ISO 및 외부 설치 결과도 같은 v8h 해시와 일치합니다.

사용자가 이전에 멈추던 아처 재현 사례 1건의 정상 진행과, v8h를 새로 부팅한 세션의 전투 진입·표시를 확인했습니다. 아처 두 수정 위치를 각각 재현하거나 세이버의 해당 장면들을 모두 플레이한 검증은 아닙니다. 전체 루트·모든 전투·PSP 실기 검증은 포함하지 않습니다.
