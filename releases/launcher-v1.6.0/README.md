## 런처 1.6.0 — 켜면 찾고, 하나 고르고, 한 번 누릅니다

화면을 처음 쓰는 사람 기준으로 다시 짰습니다. 설치 방식이나 본편 버전은 그대로이고, 기존 1.5.0 사용자는 EXE와 tools만 덮어쓰면 됩니다. `launcher-settings.json`과 `Data`는 그대로 두세요.

- 켜면 일본판 원본 ISO, PPSSPP, 메모리스틱을 스스로 찾아 채웁니다. 후보가 여럿이면 첫 후보를 넣고 나머지는 ▼에 둡니다.
- 고를 것은 「전체 설치 · 본편만 · 직접 선택」 하나입니다. 처음에는 전체 설치가 골라져 있어 본편, HD 고화질, 한국어 UI가 함께 들어갑니다.
- 큰 버튼은 하나이고 상태에 따라 「한국어 패치 설치 · 업데이트 · 다시 설치」로 바뀝니다. 개별 항목, 설치 방식, 설치 폴더, 도구 버튼, 진행 기록은 「고급」 아래로 옮겼습니다.
- 머리에 게임의 키 비주얼과 로고가 보입니다. 이 그림은 여러분이 지정한 원본 ISO 안의 것을 실행 때 읽는 것이고, 런처 ZIP에는 게임 그림이 없습니다.
- 최신 배포 줄에 공개 날짜, 이 컴퓨터 줄에 설치 날짜가 붙습니다. 진행 막대에 퍼센트 숫자가 나옵니다.
- ISO나 PPSSPP를 못 찾으면 빈 칸 이름을 밝히고, PPSSPP가 없을 때는 받을 곳으로 가는 버튼을 띄웁니다.

### 함께 고친 것

- 메모리스틱 칸에 안쪽 `PSP` 폴더를 골라도 위 폴더로 바로잡습니다. 이전에는 설치는 되는데 PPSSPP가 다른 곳을 보는 상태가 될 수 있었습니다.
- 다운로드 전에 드라이브 여유 공간을 검사하고 부족하면 필요량과 남은 양을 알려 줍니다.
- GitHub 요청 한도나 방화벽에 걸리면 배포 페이지의 고정 주소로 같은 정보를 받습니다.
- 외부 데이터 방식은 준비가 오래 걸리는 디스크에서도 실패하지 않도록 도우미가 살아 있는 동안 기다립니다. 실행 중 상태 기록이 실패해도 게임이 끊기지 않습니다.
- 진행 기록을 설치 폴더의 `Data\launcher.log`에 남깁니다. 문의할 때 이 파일을 함께 보내 주세요.

### 처음 실행할 때

이 런처는 유료 코드 서명이 없어 처음 실행할 때 「Windows의 PC 보호」 창이 뜰 수 있습니다. 「추가 정보 → 실행」을 누르면 됩니다. 아예 안 보려면 ZIP을 풀기 전에 ZIP 파일 → 속성 → 「차단 해제」를 체크하고 푸세요. 파일이 바뀌지 않았는지는 아래 `SHA256SUMS.txt`로 확인할 수 있습니다.

### 확인한 범위

- 설정 파일 없는 새 폴더에서 자동 탐색, 최신 배포 확인, 첫 화면, 고급 펼침, 본편만 전환을 실제 실행으로 확인했습니다.
- 같은 코어로 본편 + HD + 한국어 UI 전체 설치를 실제로 한 번 끝까지 진행했습니다. 만들어진 ISO의 SHA-256이 v8h와 같고, 메모리스틱의 텍스처 매핑이 한국어 UI 해시와 같으며, PPSSPP 실행까지 확인했습니다.
- 기존 단위 검사 26개를 최종 소스로 다시 통과했습니다.
- 외부 데이터 방식의 대기 시간 변경과 여유 공간 검사는 실제 저속 디스크와 꽉 찬 드라이브에서 재현하지 않았습니다. PSP 실기는 대상이 아닙니다.

본편 v8h · HD v54 · 한국어 UI v4는 [최신 본편 배포 페이지](https://github.com/sirecoymarsh/fate-extra-korean-patch/releases/tag/v8h-hd-v54-ui-v4)에 있습니다. 런처가 스스로 그 배포를 찾아 설치합니다.
