# Fate/EXTRA 한국어 패치 v8i — 시청각실 영사기 장면 무한 로딩 수정

3회전 종료 후 시청각실에서 영사기(데모 전투)를 본 뒤, 서번트 대사가 나오기 직전에 오른쪽 아래 「Now Loading」이 사라지지 않고 멈추는 문제를 수정했습니다. 세이버로 보고되었고 아처도 같은 경계에 있었습니다. 캐스터는 원래 통과합니다.

- 원인: 한국어판은 루비 글꼴과 자막 훅 때문에 상주 데이터(PRELOAD)가 일본판보다 약 229KB 큽니다. 이 장면에서 게임이 `pack/ifmodel_03.pak`(521,264바이트)를 파일 로더 힙에 올리려 할 때 세이버 구성에서는 빈 자리가 약 497KB뿐이라 할당이 실패하고, 로더가 매 프레임 재시도하면서 멈춥니다.
- 수정: 실행 파일의 파일 로더 힙(힙 3)과 C 라이브러리 힙 크기를 함께 512KB 늘렸습니다. 바뀐 것은 EBOOT 두 벌의 값 두 개, 총 4바이트입니다. 힙 시작 주소와 상주 데이터 주소는 그대로라 기존 훅과 HD 팩 매핑에 영향이 없고, 다른 malloc 사용자의 여유는 일본판과 같습니다.
- 확인: 공개판 v8h에서 같은 장면의 멈춤을 에뮬레이터로 재현했고, 수정판에서는 세이버·아처 모두 같은 장면을 지나 다음 대사로 진행했습니다(자동 진행 시험). 모든 장면을 다시 플레이한 검증은 아닙니다.
- 기존 v8h의 번역·글꼴·연출 명령 복원은 그대로입니다. HD v55와 선택 UI v5는 v8i 본편 해시에 맞춘 호환성 패키지이며 그림과 매핑은 HD v54·UI v4와 같습니다. 런처는 1.6.0을 사용합니다.
- 세이브 데이터는 그대로 이어서 쓸 수 있습니다. 새 ISO를 시작하고 게임 타이틀의 로드에서 일반 세이브를 불러오세요. 예전 PPSSPP 상태 저장은 옛 힙 크기로 돌아가므로 쓰지 마세요.

지원 원본: 일본판 NPJH50247, 1,280,933,888바이트, SHA-256 `60399D610CBCDA96601374A2E621A22BB58505C403C6FA4221EEC5E87235667B`.
원본 ISO·수정 ISO·에뮬레이터는 배포에 포함하지 않습니다. 치트와 클리어 세이브는 기존과 같이 선택 설치입니다. PSP·비타 실기는 검증하지 않았습니다.

### 설치

1. PPSSPP를 종료합니다. 런처가 없으면 아래 `Fate-Extra-Korean-Launcher.zip`(1.6.0)을 새 폴더에 풀고 실행합니다. 이미 런처를 쓰고 있으면 그대로 켜면 새 배포를 안내합니다.
2. 일본판 원본 ISO·PPSSPP·메모리스틱 경로를 확인하고 **한국어 패치 설치**를 누릅니다. 본편 v8i와 함께 HD v55·UI v5가 설치됩니다(본편만 선택도 가능).
3. 새로 부팅한 게임 타이틀에서 **로드**로 일반 세이브를 불러옵니다. 예전 PPSSPP 상태 저장은 쓰지 마세요.

수동 본편 설치는 Base ZIP의 `Apply-Patch.cmd`를 실행해 일본판 원본 ISO를 선택합니다(`Fate-Extra-Korean-v8i.iso` 생성). HD 분할 압축은 `.z01`과 `.zip`을 같은 폴더에 두고 ZIP에서 풉니다. 자세한 수동 설치는 `INSTALL-ko.txt`를 참고하세요.

### 확인 범위

원본 ISO에서의 재생성(v8g 패치 + v8h 복원 15명령 + 이번 4바이트), 지정한 바이트 외 변화 없음, 실제 런처 설치와 단독 패치 적용 결과 해시, 본편+HD+UI 설치와 UI 적용/해제, PNG 26,712장 해시를 확인했습니다. 멈춤 장면은 공개판 v8h에서 재현하고 v8i에서 세이버·아처가 통과하는 것을 격리된 PPSSPP 1.20.4에서 자동 진행으로 확인했습니다. 추가로 1회전부터 종결까지의 세이브 지점 74곳에서 세이버·아처로 자동 진행 시험 143건을 돌려 로더 멈춤이 없었습니다(같은 조건의 v8h 세이버 제어 실행은 같은 장면에서 멈춤). 이동·전투·선택 이벤트까지 포함한 모든 루트·모든 장면·PSP 실기 검증은 포함하지 않습니다.
