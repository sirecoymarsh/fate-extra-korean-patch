# Fate/EXTRA 한국어 패치

PSP 일본판 **Fate/EXTRA (NPJH50247)**용 비공식 한국어 패치입니다. 기본 한국어 패치와 PPSSPP용 선택 HD 리텍스처 팩을 따로 제공합니다.

**[배포 파일과 설치 안내](https://github.com/sirecoymarsh/fate-extra-korean-patch/releases/tag/v8e-hd-v39)**

## 이번 변경

기본 v8e와 HD v39에서 **원래 영어였던 UI를 영어로 복원**했습니다. HD의 해상도는 유지했습니다. 원래 일본어였던 UI의 한국어, 대사·설명·자막, 글꼴, 기존 인물·배경 보정은 유지합니다. 새 매핑 때문에 기본 v8e와 HD v39를 함께 사용하세요.

## Windows 선택 설치 런처

**[런처 1.2.1 다운로드](https://github.com/sirecoymarsh/fate-extra-korean-patch/releases/download/v8e-hd-v39/Fate-Extra-Korean-Launcher-v1.2.1.zip)**

ZIP을 전부 풀고 `FateExtraLauncher.exe`를 실행하세요. 본편 한국어 패치·HD 리팩·치트·클리어 세이브를 각각 선택할 수 있습니다. 새 버전은 시작할 때 알림만 표시하며, **설치 / 업데이트 버튼을 눌러야 적용**합니다. 기존 설치 자료는 자동 백업합니다.

시작 시 일본판 원본 ISO·PPSSPP·메모리스틱 위치를 자동으로 찾습니다. 1.2.1은 Windows에 남아 있는 PPSSPP 실행 경로를 먼저 확인해, 다른 드라이브의 깊은 설치 폴더도 찾습니다. 일반 위치에서 PPSSPP나 메모리스틱을 찾지 못하면 로컬 드라이브를 추가 탐색합니다. 여러 후보는 입력 칸의 **▼**에서 고르세요. PPSSPP 선택 시 해당 메모리스틱을 연결하며, 직접 지정한 폴더는 유지합니다. 다른 위치는 **폴더 안에서 찾기…**로 좁혀 탐색할 수 있습니다. HD·치트·세이브는 기본 선택이 꺼져 있습니다. 원본과 PPSSPP는 별도 준비가 필요합니다. [런처 사용법](launcher/README-ko.md) · [런처 소스](launcher/)

현재 런처는 **미서명 배포본**입니다. “Windows의 PC 보호 / 알 수 없는 게시자” 경고에 대해서는 [서명 안내](launcher/README-ko.md)를 확인하세요.

HD는 **`.z01`과 `.zip`을 둘 다 내려받아 같은 폴더에 놓은 뒤 `.zip`을 열어 전체 압축 해제**하세요. 분할 ZIP을 지원하는 반디집 등으로 풉니다. 각 조각을 따로 풀거나 파일 이름을 바꾸지 마세요. GitHub가 자동으로 만드는 `Source code (zip)`은 패치 배포 파일이 아닙니다.

## 기본 패치 적용

1. 기본 ZIP을 폴더에 전부 풉니다.
2. Windows 64비트에서 `Apply-Patch.cmd`를 실행하고 직접 보유한 일본판 원본 ISO를 선택합니다.
3. 같은 폴더에 새 `Fate-Extra-Korean-v8e.iso`가 생성됩니다. 기존 출력 파일과 원본은 덮어쓰지 않습니다.
4. 새 ISO로 게임을 시작합니다. HD 없이도 기본 한국어 패치를 사용할 수 있습니다.

지원 원본은 `NPJH50247`, `DISC_VERSION 1.01`, **1,280,933,888 bytes**인 ISO입니다. 다른 판본/수정된 ISO/CSO/CHD는 직접 적용할 수 없습니다.

```text
지원 원본 SHA-256
60399D610CBCDA96601374A2E621A22BB58505C403C6FA4221EEC5E87235667B
```

## 선택 HD 팩 설치

1. 분할 ZIP 두 파일을 함께 받아 압축 해제합니다.
2. PPSSPP를 종료하고 사용 중인 메모리스틱의 `PSP/TEXTURES/NPJH50247` 폴더를 백업합니다.
3. 압축에서 나온 `NPJH50247` 폴더를 `PSP/TEXTURES/`에 넣습니다.
4. 최종 경로가 `PSP/TEXTURES/NPJH50247/textures.ini`인지 확인하고 PPSSPP에서 텍스처 교체(Replace textures)를 켭니다.

예전 HD 팩이 필요 없는 전체 팩이며, 현재 참조 이미지 26,558개를 포함합니다. 고해상도 대사 글꼴과 HD 전용 이미지 번역·복원은 기본 v8e와 이 팩을 함께 설치해야 표시됩니다. 해상도 설정은 기기 성능에 맞춰 조정하세요. 실기 PSP는 이 PPSSPP 텍스처 팩을 사용할 수 없습니다.

## 치트와 클리어 세이브

런처에서는 필요한 항목을 선택하고 설치 버튼을 누릅니다. 수동 설치 시에는 기본 팩의 `Extras/사용법.txt`를 참고하세요. 치트·클리어 세이브를 선택하지 않으면 설치하지 않습니다.

- PPSSPP 한국어 치트 목록과 PSP CWCheat 영문 코드 목록을 동봉했습니다. 19개 모두 기본적으로 꺼져 있습니다.
- 클리어 세이브는 `NPJH50247DATA80`의 캐스터 Lv.52 / 총 37시간51분 데이터입니다. 기존 같은 슬롯을 반드시 백업하세요.
- 치트를 사용한 플레이에서 만든 세이브일 수 있으며, 진행·수치·파일은 동봉 과정에서 수정하지 않았습니다.
- PSP 실기에서 이 빌드·치트·세이브 조합은 검증하지 않았습니다.

## 저장·복원·확인 범위

새 ISO를 처음 시작할 때는 게임 메뉴의 일반 저장 불러오기를 사용하세요. 이전 빌드의 PPSSPP 상태 저장은 옛 실행 코드까지 복원할 수 있습니다.

원본 복원은 보관한 일본판 ISO를 다시 사용하는 방식입니다. HD는 텍스처 교체를 끄거나 백업한 `NPJH50247` 폴더로 되돌릴 수 있습니다. 일반 저장 파일은 별도로 보관하세요.

패치 적용 결과가 검토한 v8e 빌드와 동일함을 확인했습니다. 실행 확인 환경은 PPSSPP 1.20.4입니다. HD를 끈 기본판도 타이틀 진입, 일반 저장 불러오기, 한국어 대사 표시를 확인했습니다. **PSP 실기에서는 부팅·플레이·저장 호환을 검증하지 않았습니다.** HD 분할 ZIP의 재압축·재해제는 원래 파일 목록, 크기, CRC32와 일치하도록 검사합니다. 모든 분기·장면·기기의 무오류를 보증하지 않으며, 알려진 범위는 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)에 적었습니다.

게임 ISO, 에뮬레이터, 개인 설정이나 PPSSPP 상태 저장은 배포하지 않습니다. 원작의 권리는 원저작권자에게 있습니다. 제작·참고 자료는 [CREDITS.txt](CREDITS.txt)를 확인하세요.
