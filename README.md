# Fate/EXTRA 한국어 패치

PSP 일본판 Fate/EXTRA(NPJH50247)용 비공식 한국어 패치입니다.

**[최신 배포와 다운로드](https://github.com/sirecoymarsh/fate-extra-korean-patch/releases/tag/v8i-hd-v55-ui-v5)** — 본편 v8i · HD v55 · 선택 UI v5 · 런처 1.6.0

**[런처 내려받기](https://github.com/sirecoymarsh/fate-extra-korean-patch/releases/latest/download/Fate-Extra-Korean-Launcher.zip)** — 받을 파일은 이것 하나입니다. 배포 페이지의 나머지 파일은 런처 없이 수동 설치할 때만 필요합니다.

## 추가·변경 사항

이 절은 원판(PSP 일본판 Fate/EXTRA, NPJH50247)과 비교해 이 패치가 무엇을 더하고 바꿨는지를 커밋 기록·릴리스 노트·저장소 문서에서 모아 정리한 것입니다. 괄호 안은 근거(커밋 앞 7자, 릴리스 태그, 파일 이름)이며, 확실하지 않은 내용은 「(추정)」으로 표시했습니다.

### 번역 범위

- **기준 원문**: 일본어 원본(PSP 일본판 NPJH50247, DISC_VERSION 1.01)을 기준으로 한국어화했습니다. 기존 한국어 대본(홍련·마리봄·테스타 블로그 번역)을 참고했습니다(`CREDITS.txt`).
- **본편(기본 팩)**: 대사, 설명문, 자막(전투 음성 자막 포함), 원래 일본어로 되어 있던 UI·메뉴를 한국어로 바꿨습니다(v8e-hd-v39, v8g-hd-v53-ui-v3).
- **원래 영어였던 UI는 기본값이 영어 그대로**입니다. v8e부터 원판에서 영어로 표시되던 UI는 원본 영어로 되돌렸습니다(54ce142, v8e-hd-v39). 이 부분은 아래 「선택 UI 한국어화」로 따로 한국어화할 수 있습니다.
- **선택 UI 한국어화 팩**: 원판에서 영어였던 UI 138개(메인 메뉴, 전투 UI, 타이틀 안내, HUD, 아이콘, 전투 메시지 등)를 한국어 그림으로 교체합니다. 서번트 카드의 코드·변수명 같은 영문 표기는 일부러 바꾸지 않았습니다(e73e753, v8e-hd-v40, v8e-ui-v1).
- **HD 팩 전용 번역**: 고해상도 대사 글꼴과 함께 HD 전용 일본어 UI·엔딩(스태프롤 등) 번역·복원이 HD 팩을 설치할 때 적용됩니다(v8d-hd-v38, v8e-hd-v39).
- **용어·문체 손질**: 「게이 볼그」 표기를 469곳 통일했고, 트와이스 대사 430단위를 검토해 원문의 독특한 문체를 살려 369곳을 고쳤습니다(v8g-hd-v53-ui-v3, `releases/v8g-hd-v53-ui-v3/adopted-native-plan.json`).
- **이름 입력**: 주인공 기본 이름을 영어 기본 이름으로 입력·표시하도록 했고, 긴 이름이 잘리지 않게 필드 표시를 조정했습니다(v8g-hd-v53-ui-v3).
- **남은 부분**: 일부 엔딩 스태프 이름의 읽기는 아직 확정되지 않았습니다(`KNOWN_ISSUES.md`).

### 편의 기능

- **선택 설치 런처**(Windows): 본편·HD 고화질 팩·UI 한국어화·치트·클리어 세이브를 골라 설치하고, 새 배포 알림 뒤 버튼으로 업데이트합니다. 기존 자료는 자동으로 백업합니다(1ec1d39, 런처 1.0.0~1.6.0).
- **치트 19종(선택)**: PPSSPP용 한국어 이름 / PSP CWCheat용 영문 이름으로 넣었으며 모두 꺼진 상태로 설치됩니다. 런처는 PPSSPP의 「치트 사용」만 켭니다. wikiwiki의 기존 코드에 이 프로젝트가 만든 경험치·과거 이야기 코드를 더했습니다(v8d-hd-v38, `CREDITS.txt`).
- **클리어 세이브(선택)**: 캐스터 Lv.52, 플레이 시간 37시간 51분, 슬롯 DATA80. 치트 사용 이력이 있을 수 있습니다(v8d-hd-v38).
- **외부 데이터 로딩 방식**: 한국어 ISO 파일을 따로 만들지 않고, 원본 ISO와 차분 데이터를 런처의 보조 프로세스가 PPSSPP에 공급합니다. 이 방식은 실행할 때마다 원본 ISO가 필요하고 런처의 「게임 실행」으로 시작해야 합니다(70dfb7d, launcher-v1.5.0, `launcher/EXTERNAL-DATA.md`).
- **PPSSPP 권장 설정 자동 적용**: HD/UI 설치 때 Fate/EXTRA 전용 설정 파일(`PSP/SYSTEM/NPJH50247_ppsspp.ini`)에 렌더링 해상도 8배, MSAA 4배, 수직동기화, 텍스처 교체 켜기를 적용합니다. 기존 설정은 백업하고 다른 게임용 전역 설정은 건드리지 않습니다. 느린 인터프리터 설정은 JIT로 바로잡되, 이미 고른 JIT/JIT-IR은 그대로 둡니다(95c9343, v8e-ui-v1, v8f-hd-v52-ui-v2).
- **UI 한국어화 적용/해제**: HD를 다시 받지 않고 한국어 UI와 원래 영문 UI 사이를 전환합니다. HD를 업데이트해도 이미 적용한 한국어 UI는 유지됩니다(v8e-ui-v1).

### 단축키·조작

게임 안의 키 배치는 원판과 같습니다. 이 패치가 새로 넣은 게임 내 단축키는 저장소 자료에서 찾지 못했습니다. 컨트롤러 설정은 런처가 PPSSPP 설정을 바꿀 때도 사용자의 기존 값을 유지합니다(`launcher/CpuDefaultsTests.cs`).

### 화면·그래픽 개선

- **HD 고화질 텍스처 팩(선택, PPSSPP 전용)**: Fate-AI-HD-Team/Fate-Extra-HD를 바탕으로 배경·인물·UI 그림을 고해상도로 바꿉니다. Real-ESRGAN 확대와 이미지 생성 도구를 이용한 재구성을 포함하며, 원본의 미세 묘사를 모두 복원했다고 보증하지는 않습니다(`CREDITS.txt`, v8d-hd-v38).
- **누적 그림 수정**: HD v41~v52에서 승인한 수정 그림 2,867장과 연결 정보 5,806개를 넣었습니다. 캐릭터·매트릭스 그림, 배경과 소품, 문셀·최종전 돌기둥, 디지털 숫자, 세이비어 눈동자 수정이 들어 있습니다(82f7beb, v8f-hd-v52-ui-v2). 현재 HD 팩의 PNG는 26,712장입니다(v8h, v8i).
- **글꼴**: Noto Sans KR / Noto Serif KR을 썼습니다. 전투·대사·백로그 글꼴을 골라 쓰도록 했고(speech v2), 전투 음성 자막과 필드 대사는 명조체로 표시합니다. HD 팩에서는 고해상도 대사 글꼴이 적용됩니다. 루비(윗첨자 읽기) 글꼴도 넣었습니다(v8g-hd-v53-ui-v3, v8i 릴리스 노트).
- **UI 배치 보정**: 마스터 레벨의 한글 크기와 숫자 옆 배치, 상점 버튼 5개 가운데 정렬, 상태 화면 라벨의 세로 위치, 「CANCEL」 높이 통일을 맞췄습니다. 한국어 UI를 끄면 원래 영문 UI 위치가 그대로 유지되도록 했습니다(6cfa473, v8g-hd-v53-ui-v3, `releases/v8g-hd-v53-ui-v3/README.md`).
- **UI 단독 팩**: HD 고화질 팩 없이 한국어 UI만 쓰는 `Fate-Extra-Korean-UI-only-v4.zip`(텍스처 매핑 750개, PNG 283장, 약 1.5MB)을 추가했습니다. 안드로이드 PPSSPP에서도 손으로 넣어 쓸 수 있습니다(a27ef42).
- **넣지 않은 것**: 북쪽 고정 카메라, 타마모 3D 머리카락 형태 수정은 포함하지 않았습니다(`KNOWN_ISSUES.md`).

### 버그 수정

- **매트릭스 로딩 문제**: 매트릭스 로딩을 망가뜨리던 압축 자료 11곳을 고쳤습니다(82f7beb, v8f-hd-v52-ui-v2). 매트릭스 상세 화면이 느려지던 JIT 설정도 교정했습니다(v8g-hd-v53-ui-v3).
- **아처·세이버 연출 명령 손상**: 문자열 재배치 과정에서 텍스트 주소로 잘못 바뀐 아처 2곳·세이버 13곳의 연출 명령(총 15개 명령, 30바이트)을 원본으로 되돌렸습니다. 아처로 진행하다 멈추던 사례가 이 수정으로 해결됐습니다(0afbdee, v8h-hd-v54-ui-v4, `v8h-opcode-plan.json`).
- **3회전 종료 후 시청각실 영사기 장면 무한 로딩**: 영사기(데모 전투)를 본 뒤 서번트 대사 직전에 오른쪽 아래 「Now Loading」이 사라지지 않던 문제를 고쳤습니다. 한국어판의 상주 데이터(루비 글꼴·자막 훅)가 일본판보다 약 229KB 커서 파일 로더 힙이 모자랐던 것이 원인이며, 실행 파일(EBOOT.BIN·BOOT.BIN)의 로더 힙과 C 라이브러리 힙을 각각 512KB 늘렸습니다(총 4바이트 변경). 세이버로 보고됐고 아처도 같은 경계에 있었습니다(e75c19b, v8i-hd-v55-ui-v5, `v8i-heap-plan.json`).
- **런처 경로 탐색 문제**: 깊은 폴더나 다른 드라이브에 있는 PPSSPP·메모리스틱을 못 찾던 문제(1.2.0, 1.2.1), 메모리스틱 칸에 안쪽 `PSP` 폴더를 고르면 PPSSPP가 다른 곳을 보던 문제(1.6.0)를 고쳤습니다(3073425, aa0879b, fea0d4b).

### 설치·제거 방식

- **원본 확인**: 일본판 NPJH50247, DISC_VERSION 1.01, 1,280,933,888바이트, SHA-256 `60399D61…7235667B` 원본만 받습니다. 다른 판본·수정된 ISO·CSO·CHD는 직접 적용하지 않습니다.
- **본편 적용**: xdelta3(VCDIFF) 차분으로 원본을 바꾸지 않고 새 한국어 ISO를 만듭니다. 런처 없이도 기본 팩의 `Apply-Patch.cmd`로 적용할 수 있습니다. 런처는 받은 파일·원본·결과물을 모두 크기와 SHA-256으로 확인한 뒤에만 씁니다.
- **HD·UI**: 메모리스틱의 `PSP/TEXTURES/NPJH50247`에 넣는 텍스처 교체 팩입니다. HD는 2GB 미만으로 나눈 분할 ZIP(`.z01` + `.zip`)입니다. 런처는 설치 전 기존 파일을 백업하고, 실패하면 되돌립니다.
- **제거·복원**: UI 한국어화는 런처의 「UI 한국어화 해제」로 원래 영문 UI로 돌립니다. HD·UI 단독 팩은 해당 폴더를 지우면 원래대로 돌아갑니다. 원본 ISO와 사용자의 PPSSPP 설치본은 바꾸지 않습니다.
- **지원 환경**: Windows 64비트 + PPSSPP(시험 환경 1.20.4). 안드로이드는 UI 단독 팩 수동 설치만 안내합니다. PSP·비타 실기는 검증하지 않았고, HD 팩은 실기에서 쓸 수 없습니다.
- **세이브**: 게임 안 일반 저장은 판이 바뀌어도 이어서 쓸 수 있습니다. PPSSPP 상태 저장(스테이트)은 옛 실행 코드를 되살리므로 쓰지 말라고 안내합니다.

### 알려진 문제

- 모든 루트·모든 전투·모든 장면을 다시 플레이한 검증은 아닙니다. v8i 수정은 자동 진행 시험(세이브 지점 74곳, 143건)으로 확인했습니다.
- 공개하지 않은 PSP 실기용 판(v8h-psp)에는 v8i의 힙 수정이 들어 있지 않습니다. PSP·비타 실기 호환성은 검증하지 않았습니다.
- 일부 엔딩 스태프 이름의 읽기가 확정되지 않았고, 후반 모든 표정의 실행 중 재확인이 남아 있습니다(v8d·v8e 릴리스 노트).
- HD 그림에는 AI 재구성이 들어 있어 원본의 미세 묘사와 다를 수 있습니다.
- 북쪽 고정 카메라와 타마모 3D 머리카락 형태 수정은 넣지 않았습니다.
- UI 단독 팩을 넣은 상태에서는 런처 1.6.0이 HD·UI 설치를 거부합니다. 먼저 `PSP/TEXTURES/NPJH50247` 폴더를 지워야 합니다. 안드로이드에서는 시험하지 않았습니다.
- 외부 데이터 방식은 원본 ISO를 계속 갖고 있어야 하며, 보조 프로세스를 강제로 끝내면 게임이 끊깁니다. PSP 실기용 외부 로더는 없습니다.
- 런처는 코드 서명이 없어 처음 실행할 때 SmartScreen 경고가 뜰 수 있습니다.
- 자세한 확인 범위는 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)를 보세요.

## 설치

런처 1.6.0은 켜면 일본판 원본 ISO·PPSSPP·메모리스틱을 스스로 찾고, 「전체 설치」 또는 「본편만」을 고른 뒤 「설치」 한 번으로 끝납니다. 설치 방식은 **한국어 ISO 파일 만들기**가 기본이고, **외부 데이터 로딩 · ISO 생성 안 함**은 「고급」에 있습니다. 외부 방식은 실행할 때도 원본 ISO가 필요하며 게임은 런처에서 실행합니다. 방식을 바꾼 뒤에는 설치를 다시 눌러야 적용됩니다. [런처 1.6.0 릴리즈](https://github.com/sirecoymarsh/fate-extra-korean-patch/releases/tag/launcher-v1.6.0)

16MB 이상 파일은 **4개 구간을 동시에 다운로드**합니다. 각 구간을 이어받고 합친 파일을 검증하며, 서버가 구간 전송을 지원하지 않으면 일반 다운로드로 전환합니다.

런처 ZIP을 새 폴더에 풀고 실행합니다. 처음 실행할 때 「Windows의 PC 보호」 창이 뜨면 「추가 정보 → 실행」을 누르세요. ZIP 파일의 속성에서 「차단 해제」를 체크하고 풀면 이 창이 뜨지 않습니다. 찾아 놓은 경로를 확인하고 **한국어 패치 설치**를 누르면 됩니다. HD/UI/치트/클리어 세이브는 PPSSPP 메모리스틱 폴더가 필요합니다.

| 선택 | 화면 |
| --- | --- |
| 본편 | 한국어 대사·설명 + 원래 영문 UI |
| 본편 + HD | 고화질 그림·글꼴 + 원래 영문 UI |
| 본편 + HD + UI 한국어화 | 고화질 + 한국어 UI·아이콘·전투 메시지 |

시작할 때 최신 배포를 확인하며 다운로드·적용은 버튼을 눌러야 진행됩니다. 런처 실행 파일 자체는 자동 교체하지 않습니다. 이미 적용한 UI 한국어화는 HD 업데이트 시 유지되며, 원래 UI로 돌아가려면 **UI 한국어화 해제**를 사용합니다.

## 이번 배포

- 본편 v8i: 3회전 종료 후 시청각실에서 영사기(데모 전투)를 본 뒤 서번트 대사 직전에 「Now Loading」이 멈추던 문제(세이버 보고, 아처도 같은 경계)를 수정했습니다. 한국어판의 상주 데이터가 일본판보다 커져 파일 로더 힙이 모자라던 것이 원인이라, 로더 힙과 C 라이브러리 힙을 512KB 늘렸습니다(EBOOT 4바이트). 기존 v8h의 번역·글꼴·연출 명령 복원은 유지합니다.
- HD v55·선택 UI v5: v8i 호환성 정보 갱신이며 그림과 매핑은 HD v54·UI v4와 같습니다.
- 런처 1.6.0: 켜면 경로를 찾고, 전체 설치 또는 본편만을 고른 뒤 설치 한 번입니다. 외부 데이터 로딩은 고급에 있습니다.
- UI 단독 팩: HD 고화질 팩 없이 UI 한국어화만 넣는 `Fate-Extra-Korean-UI-only-v4.zip`은 그대로입니다(그림은 UI v5와 같음). 수동·안드로이드용입니다.

공개판 v8h에서 같은 장면의 멈춤을 에뮬레이터로 재현했고, v8i에서는 세이버·아처 모두 그 장면을 지나 다음 대사로 진행했습니다(자동 진행 시험). 모든 루트와 장면을 다시 플레이한 검증은 아닙니다. 세이브 데이터는 그대로 이어서 쓸 수 있고, 예전 PPSSPP 상태 저장은 쓰지 마세요.

## PPSSPP 설정과 저장

HD/UI 설치 시 Fate/EXTRA 전용 설정에 렌더링 8배, MSAA 4배, 수직동기화·텍스처 교체 켜기를 적용합니다. 기존 JIT 설정과 전역 설정은 보존합니다. MSAA 지원과 성능은 백엔드·기기에 따릅니다. 설치·업데이트 전에는 PPSSPP를 종료하세요.

치트는 선택 설치입니다. PPSSPP의 치트 사용 기능만 켜며 개별 코드 19개는 모두 꺼져 있습니다. 클리어 세이브도 선택 설치이고 선택하지 않은 저장 데이터는 변경하지 않습니다. 동봉 클리어 세이브는 캐스터 Lv.52 / 37시간51분이며 치트 사용 이력이 있을 수 있습니다. 기존 같은 슬롯은 보관하세요.

새 ISO를 시작한 뒤 게임 타이틀에서 일반 저장을 불러오세요. 이전 PPSSPP 상태 저장에는 옛 실행 코드가 들어 있습니다.

## 파일과 지원 원본

- `Fate-Extra-Korean-Launcher-v1.6.0.zip` — 고정 이름 사본 `Fate-Extra-Korean-Launcher.zip`과 같은 파일
- `Fate-Extra-Korean-Base-v8i.zip`

수동 본편 설치는 기본 팩의 `Apply-Patch.cmd`를 실행해 일본판 원본 ISO를 선택합니다. 원본을 보존하며 같은 폴더에 `Fate-Extra-Korean-v8i.iso`를 생성합니다. 수동 HD 설치는 기존 폴더를 백업하고 압축을 푼 `NPJH50247` 폴더를 메모리스틱의 `PSP/TEXTURES`에 넣은 뒤 PPSSPP의 텍스처 교체를 켭니다. 수동 UI 설치는 UI ZIP의 `files/KoreanHD`를 해당 폴더에 합치고 `korean-textures.ini`를 `textures.ini`로 이름을 바꿔 덮어씁니다.

**HD 없이 UI 한국어화만** 쓰려면 `Fate-Extra-Korean-UI-only-v4.zip` 안의 `NPJH50247` 폴더를 메모리스틱의 `PSP/TEXTURES`에 넣고 PPSSPP의 텍스처 교체를 켭니다. 안드로이드 PPSSPP도 같습니다(설정 → 시스템 → 메모리스틱 폴더). 이 팩은 HD 팩과 같이 쓰지 않으며, 나중에 런처로 HD를 설치하려면 그 `NPJH50247` 폴더를 먼저 지우세요. 되돌리려면 폴더를 지우면 됩니다.
