# Fate/EXTRA 한국어 패치

PSP 일본판 **Fate/EXTRA (NPJH50247)**용 비공식 한국어 패치입니다. 기본 한국어 패치와 PPSSPP용 선택 HD 리텍스처 팩을 따로 제공합니다.

**[배포 파일과 설치 안내](https://github.com/sirecoymarsh/fate-extra-korean-patch/releases/tag/v8e-ui-v1)**

## 선택 UI 한국어화 + 런처 1.4.0

고화질과 UI 한국어화를 따로 선택할 수 있도록 분리했습니다.

| 구성 | 화면 |
| --- | --- |
| 본편 한국어 패치만 | 한국어 대사·설명 + 원래 영문 UI |
| 본편 + HD 고화질 팩 | 고화질 그림·글꼴 + 원래 영문 UI |
| 본편 + HD + UI 한국어화 | 고화질 + 한국어 UI·아이콘·전투 메시지 |

별도 **UI 한국어화**는 기본 선택이 꺼져 있으며 약 8.5 MB입니다. 기존에 영어였던 UI 138개를 교체합니다. 원래 일본어였던 부분의 기존 한국어 번역은 유지되며, 서번트 카드의 코드·변수명은 바꾸지 않습니다. 기본 본편 v8e와 HD v39는 기존 배포 파일을 그대로 사용합니다.

### 기존 사용자

런처를 종료하고 **Fate-Extra-Korean-Launcher-v1.4.0.zip**의 내용물을 기존 런처 폴더에 풀어 교체하세요. `launcher-settings.json`과 `Data`는 보관합니다. 이번 선택 UI 기능에는 새 런처가 필요하며, 실행 파일 자체는 자동 교체하지 않습니다.

- **HD v39 사용 중:** 한국어 UI를 원하면 `UI 한국어화`만 선택하고 설치 / 업데이트를 누르세요.
- **통합 HD v40 사용 중:** 한국어 UI를 유지하려면 `UI 한국어화`를 선택해 설치하세요. 원래 영문 UI를 원하면 `UI 한국어화 해제`를 누르세요. 전체 HD를 다시 받지 않고 전환합니다.
- **처음 HD 설치:** `HD 고화질 팩`을 선택하고, 원할 때만 `UI 한국어화`도 함께 선택하세요.
- 체크 해제는 다음 설치 대상에서 제외하는 동작입니다. 이미 적용한 한국어 UI를 지우려면 **UI 한국어화 해제** 버튼을 사용하세요. 이후 HD를 업데이트해도 이전에 선택 설치한 한국어 UI는 유지됩니다.

시작할 때는 업데이트 알림만 표시합니다. 사용자가 버튼을 눌러야 다운로드·적용합니다. 본편 v8e를 다시 패치할 필요는 없습니다.

### PPSSPP 기본 설정

HD/UI 설치 또는 첫 게임 실행 시 Fate/EXTRA 전용 설정에 **렌더링 해상도 8배, MSAA 4배, 수직동기화, 텍스처 교체**를 적용합니다. 이미 설치한 사용자는 **그래픽 기본 설정 적용** 버튼으로 적용할 수 있습니다. 첫 적용 후 게임에서 직접 조정한 값은 매 실행마다 덮어쓰지 않습니다. HD/UI 재설치 또는 설정 적용 버튼은 요청한 기본값을 다시 적용합니다.

**치트 설치 시 PPSSPP의 ‘치트 사용’만 켭니다.** 동봉 코드 19개는 모두 꺼진 상태이며, 게임 중 PPSSPP 치트 목록에서 필요한 코드를 직접 선택하세요. 그래픽 설정 버튼도 해당 프로필에 치트 파일이 있으면 치트 사용을 켭니다. 기존 치트 코드의 선택 상태를 그래픽 설정 버튼이 바꾸지는 않습니다.

설정은 `PSP/SYSTEM/NPJH50247_ppsspp.ini`에 적용하며 기존 설정을 백업합니다. PPSSPP의 다른 게임용 전역 설정은 유지됩니다. MSAA의 실제 지원 여부는 사용 중인 그래픽 백엔드·기기에 따릅니다. 업데이트·설정 변경 전 PPSSPP를 종료하세요.

### 배포 구성

- `Fate-Extra-Korean-Launcher-v1.4.0.zip`: 선택 설치 런처
- `Fate-Extra-Korean-Base-v8e.zip`: 기본 한국어 패치와 선택 치트·클리어 세이브
- `Fate-Extra-Korean-HD-v39.z01` + `.zip`: 원래 영문 UI를 유지한 HD 고화질 팩
- `Fate-Extra-Korean-UI-v1.zip`: 선택 UI 한국어화·원래 UI 복원 자료, 런처로 적용

수동 HD 설치는 두 분할 파일을 같은 폴더에 받고 `.zip`을 열어 전체 압축을 푼 뒤 `NPJH50247`을 메모리스틱의 `PSP/TEXTURES/`에 넣으세요. UI팩의 매핑 파일만 복사하면 이미지가 누락될 수 있으므로 UI 전환에는 런처를 사용하세요.

### 확인 범위

기존 검증된 UI 138개·raw/clear 조합 276개의 그림과 매핑을 재사용합니다. 이번 분리는 새로 그리거나 번역하는 변경이 아닙니다. 실제 배포 압축의 설치, HD 단독/한국어 UI 추가/해제/통합 v40 복원/기존 선택 유지, 개별 치트 OFF, 전용 그래픽 설정, 설치 실패 복구를 별도 시험 폴더에서 확인했습니다. 사용자 게임을 조작하거나 전체 장면을 다시 플레이하지 않았습니다. PSP 실기에서 HD팩은 사용할 수 없습니다.

원본 게임 ISO·PPSSPP·개인 세이브 및 개인 설정은 포함하지 않습니다.


## 기본 패치 적용

1. 기본 ZIP을 폴더에 전부 풉니다.
2. Windows 64비트에서 `Apply-Patch.cmd`를 실행하고 직접 보유한 일본판 원본 ISO를 선택합니다.
3. 같은 폴더에 새 `Fate-Extra-Korean-v8e.iso`가 생성됩니다. 기존 출력 파일과 원본은 덮어쓰지 않습니다.
4. 새 ISO로 게임을 시작합니다. HD 없이도 기본 한국어 패치를 사용할 수 있습니다.

지원 원본은 `NPJH50247`, `DISC_VERSION 1.01`, **1,280,933,888 bytes**인 ISO입니다. 다른 판본/수정된 ISO/CSO/CHD는 직접 적용할 수 없습니다.

```text
지원 원본 SHA-256
60399D610CBCDA96601374A2E621A22BB58505C403C6FA4221EEC5E87235667B
```

## 치트와 클리어 세이브

런처에서는 필요한 항목을 선택하고 설치 버튼을 누릅니다. 수동 설치 시에는 기본 팩의 `Extras/사용법.txt`를 참고하세요. 치트·클리어 세이브를 선택하지 않으면 설치하지 않습니다.

- PPSSPP 한국어 치트 목록과 PSP CWCheat 영문 코드 목록을 동봉했습니다. 19개 모두 기본적으로 꺼져 있습니다.
- 클리어 세이브는 `NPJH50247DATA80`의 캐스터 Lv.52 / 총 37시간51분 데이터입니다. 기존 같은 슬롯을 반드시 백업하세요.
- 치트를 사용한 플레이에서 만든 세이브일 수 있으며, 진행·수치·파일은 동봉 과정에서 수정하지 않았습니다.
- PSP 실기에서 이 빌드·치트·세이브 조합은 검증하지 않았습니다.

## 저장·복원·확인 범위

새 ISO를 처음 시작할 때는 게임 메뉴의 일반 저장 불러오기를 사용하세요. 이전 빌드의 PPSSPP 상태 저장은 옛 실행 코드까지 복원할 수 있습니다.

원본 복원은 보관한 일본판 ISO를 다시 사용하는 방식입니다. 선택 UI는 런처의 UI 한국어화 해제로 복원하며, 전체 HD는 텍스처 교체를 끄거나 백업한 `NPJH50247` 폴더로 되돌릴 수 있습니다. 일반 저장 파일은 별도로 보관하세요.

패치 적용 결과가 검토한 v8e 빌드와 동일함을 확인했습니다. 실행 확인 환경은 PPSSPP 1.20.4입니다. HD를 끈 기본판도 타이틀 진입, 일반 저장 불러오기, 한국어 대사 표시를 확인했습니다. **PSP 실기에서는 부팅·플레이·저장 호환을 검증하지 않았습니다.** HD 분할 ZIP의 재압축·재해제는 원래 파일 목록, 크기, CRC32와 일치하도록 검사합니다. 모든 분기·장면·기기의 무오류를 보증하지 않으며, 알려진 범위는 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)에 적었습니다.

게임 ISO, 에뮬레이터, 개인 설정이나 PPSSPP 상태 저장은 배포하지 않습니다. 원작의 권리는 원저작권자에게 있습니다. 제작·참고 자료는 [CREDITS.txt](CREDITS.txt)를 확인하세요.
